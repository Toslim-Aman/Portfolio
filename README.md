# Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, education, projects, and contact information.

## About the Project

This portfolio website was built using **HTML, CSS, and JavaScript** to create a modern, responsive, and interactive personal website.

It includes sections for:

* About Me
* Skills, Experience & Education
* Services
* Project Showcase
* Contact Form
* Downloadable CV

## Features

* Responsive Design (Mobile Friendly)
* Interactive Skills / Experience / Education Tabs
* Smooth Scrolling Navigation
* Portfolio Project Showcase
* Contact Form Connected with Google Sheets
* Social Media Links
* Downloadable CV

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Apps Script (Google Sheets Integration)
